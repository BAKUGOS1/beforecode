# Support

BeforeCode is a community-maintained open-source documentation toolkit.

## Use the right channel

- **Question or usage problem:** open a GitHub issue using the question template
- **Bug, broken link, or inconsistency:** use the bug report template
- **Template or example idea:** use the feature request template
- **Security concern:** follow [SECURITY.md](SECURITY.md)
- **Contribution:** read [CONTRIBUTING.md](CONTRIBUTING.md)

## Before asking for help

1. Read the [Getting Started guide](docs/getting-started.md).
2. Check the [project type guide](docs/project-types.md).
3. Compare your use case with the [complete examples](examples/README.md).
4. Search existing issues.

When opening an issue, describe the project type, document being used, expected result, and what is unclear. Do not post credentials, customer data, private documents, or confidential architecture details.
