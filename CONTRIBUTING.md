# Contributing

Thank you for improving BeforeCode.

## Good contributions

- New documentation templates
- Better checklists
- Filled example projects
- Clearer guides
- Prompt improvements
- Typo and formatting fixes

## Contribution rules

1. Keep templates practical and beginner-friendly.
2. Avoid placeholders that do not explain what to write.
3. Prefer Markdown files.
4. Add examples where possible.
5. Keep filenames lowercase and hyphen-separated.

## Suggested branch names

```text
docs/add-prd-template
template/add-api-docs
checklist/add-launch-review
example/add-saas-crm
```
