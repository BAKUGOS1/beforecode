# Build From Docs Prompt

Use this prompt when the project docs are ready.

```text
Read the project documentation first.

Use these files as the source of truth:
- Project Brief
- PRD
- TRD
- Database Schema
- API Documentation
- QA Test Plan
- Implementation Plan

Work phase by phase.
Keep the implementation aligned with the documented scope.
Update the README when needed.
Report missing requirements before making major assumptions.
```
