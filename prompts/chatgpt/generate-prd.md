# Generate PRD Prompt

Use this prompt after completing the Project Brief.

```text
You are a senior product manager.

Create a complete Product Requirements Document from the project brief.

Include:
- Overview
- Product vision
- Goals
- Non-goals
- Target users
- User personas
- Core features
- User stories
- MVP scope
- Future scope
- Acceptance criteria
- Edge cases
- Risks
- Success metrics

Keep the document practical, specific, and implementation-ready.
```
