# Template Catalog

Use only the documents your project needs. Start small and add depth when complexity, risk, team size, or compliance requires it.

## Discovery and Product

| Template | Use it to |
|---|---|
| [Project Brief](project-brief.md) | Define the problem, audience, value, scope, and success |
| [Research Report](research-report.md) | Capture evidence, competitors, gaps, and recommendations |
| [Business Requirements](business-requirements.md) | Define business objectives, rules, stakeholders, and KPIs |
| [PRD](prd.md) | Specify product behavior, users, requirements, and acceptance |
| [SRS](srs.md) | Record formal functional, interface, data, and constraint requirements |
| [Release Scope](release-scope.md) | Lock what is and is not included in a release |

## Experience and Access

| Template | Use it to |
|---|---|
| [UX Flows](ux-flows.md) | Map journeys, navigation, states, and recovery paths |
| [UI System](ui-system.md) | Define design tokens, components, behavior, and accessibility |
| [Permission Matrix](permission-matrix.md) | Define role and record-level access rules |

## Engineering

| Template | Use it to |
|---|---|
| [TRD](trd.md) | Define architecture, stack, boundaries, reliability, and security |
| [Database Schema](database-schema.md) | Define entities, fields, relationships, constraints, and indexes |
| [API Documentation](api-documentation.md) | Define contracts, auth, errors, pagination, and lifecycle rules |
| [Decision Record](decision-record.md) | Preserve important architecture or product decisions |

## Delivery and Quality

| Template | Use it to |
|---|---|
| [Implementation Plan](implementation-plan.md) | Convert specifications into ordered delivery phases |

## Recommended naming in your project

```text
docs/
  01-project-brief.md
  02-research-report.md
  03-prd.md
  04-trd.md
  05-database-schema.md
  06-api-documentation.md
  07-qa-test-plan.md
  08-implementation-plan.md
```

Keep decisions consistent across documents. A role, field, endpoint, status, or requirement should not silently change names between files.
