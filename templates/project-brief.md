## 1. One-Sentence Summary

Describe the product, target user, and primary value in one sentence.

## 2. Problem

- What problem exists today?
- Who experiences it?
- How is it solved now?
- Why are current alternatives insufficient?
- What evidence supports the problem?

Describe the change the product should create for users or the business. Avoid listing features here.

## 5. Value Proposition

Why should a target user choose this product instead of doing nothing or using an alternative?

## Approval Criteria

- The problem and primary user are specific
- MVP and out-of-scope boundaries are clear
- Success can be measured
- Major constraints and risks are visible
- Decision owners approve moving to detailed requirements
