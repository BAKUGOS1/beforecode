## Small Project

- Project Brief
- PRD
- Build Plan
- README

## SaaS Project

Recommended docs:

- Project Brief
- Research Report
- PRD
- TRD
- Database Schema
- API Documentation
- QA Test Plan
- Deployment Plan

## CRM Project

Recommended docs:

- Project Brief

## AI Agent

Recommended docs:

- Project Brief
- PRD
- Agent Workflow
