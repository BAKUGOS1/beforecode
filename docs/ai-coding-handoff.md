# AI Coding Handoff

AI coding agents work better with bounded objectives, approved source documents, repository rules, and explicit verification.

## Minimum Package

- Repository instructions
- Approved PRD
- TRD and decision records
- Database/API/permission docs
- UX flow
- QA plan
- Implementation plan

## Decision Boundaries

Require human approval for destructive operations, production changes, new external services, permission changes, and undocumented scope expansion.
