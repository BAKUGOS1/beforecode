# Getting Started

BeforeCode is modular. Pick the smallest useful track for your project.

## Tracks

```text
Lean: Project Brief → PRD → Build Plan → QA
Product: Brief → Research → PRD → UX → TRD → Data/API → QA → Implementation
High-risk: Add SRS, permission matrix, decisions, threat model, deployment, and approval records
```

## Recommended folder

```text
docs/
  01-project-brief.md
  02-research-report.md
  03-prd.md
  04-ux-flows.md
  05-trd.md
  06-database-schema.md
  07-api-documentation.md
  08-qa-test-plan.md
  09-implementation-plan.md
```

Use the CLI to generate this structure.
