# Research Report

## Objective

Define the foundation for BeforeCode: a practical starter kit for planning software projects before coding starts.

## Problem

Projects often fail or become messy because builders start implementation before defining product scope, technical approach, database structure, API behavior, QA checks, and delivery plan.

## Target users

- Developers
- Students
- Product builders
- Startup founders
- QA testers
- Open-source maintainers
- AI-assisted coding users

## Existing solution gaps

Most resources focus on one area only:

- README guidance
- PRD templates
- SRS templates
- API docs
- Architecture diagrams
- Prompt examples

BeforeCode combines these into one workflow.

## Recommended workflow

```text
Idea → Research → PRD → TRD → Database → API → QA → Implementation
```

## MVP scope

The first version should be Markdown-only:

- README
- Core templates
- Checklists
- Prompt files
- Example documentation packs

## Positioning

BeforeCode helps you plan a project before writing code.

## Future scope

- Documentation website
- CLI generator
- More examples
- Documentation completeness score
