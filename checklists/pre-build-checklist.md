# Pre-Build Checklist

Use this before starting implementation.

## Product clarity

- [ ] Project name is final
- [ ] Problem statement is clear
- [ ] Target users are defined
- [ ] MVP scope is clear
- [ ] Out-of-scope items are listed

## Technical clarity

- [ ] Tech stack is selected
- [ ] Database plan exists
- [ ] API plan exists
- [ ] Roles and access are defined

## Quality clarity

- [ ] Acceptance criteria are written
- [ ] QA test plan exists
- [ ] Error states are considered
- [ ] README is prepared
