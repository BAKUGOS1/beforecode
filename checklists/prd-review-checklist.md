# PRD Review Checklist

Use this to review a Product Requirements Document.

## Required sections

- [ ] Overview
- [ ] Product vision
- [ ] Goals
- [ ] Non-goals
- [ ] Target users
- [ ] Core features
- [ ] User stories
- [ ] MVP scope
- [ ] Acceptance criteria
- [ ] Edge cases
- [ ] Risks
- [ ] Success metrics

## Quality checks

- [ ] Requirements are specific
- [ ] Features are prioritized
- [ ] Scope is realistic
- [ ] Future scope is separate
- [ ] No major ambiguity remains
