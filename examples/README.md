# Example Documentation Packs

Examples show how separate BeforeCode documents should work together as one source of truth.

A complete multi-user SaaS CRM example.

Includes project brief, PRD, TRD, PostgreSQL schema, API documentation, role permissions, QA coverage, and phased implementation.

## TaskPilot

A production-oriented human-supervised AI agent example.

Includes research, product and technical requirements, explicit workflow state, database and API plans, tool permissions, memory, threat model, evaluation, QA, and implementation.

[Explore TaskPilot →](ai-agent/README.md)

## What makes a strong example

- One consistent product and vocabulary
- Requirements linked to architecture and tests
- Explicit scope and non-goals
- Realistic permissions, errors, limits, and edge cases
- Measurable acceptance and release criteria
- No unexplained placeholders
